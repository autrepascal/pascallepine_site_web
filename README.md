# pascallepine.ca

Site personnel de Pascal Lépine.

## Déploiement

Site statique HTML déployé sur Vercel.

- Push sur la branche `main` → déploiement automatique
- Domaine : pascallepine.ca (à brancher)

## Fichier principal

`index.html` — tout le site (HTML + CSS + JS inline)

## Formulaire de contact

Le formulaire utilise [Formspree](https://formspree.io/) pour relayer les soumissions par courriel.
L'ID Formspree doit être configuré dans la balise `<form>` (rechercher `formspree.io/f/`).
